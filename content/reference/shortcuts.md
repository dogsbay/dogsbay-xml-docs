# Keyboard shortcuts

These are the defaults. Every one of them can be changed in **File > Settings > Bindings**, which also lists the commands that have no key until you give them one.

**Ctrl** here means the platform's menu key: Control on Linux and Windows, Command on macOS.

## Files

| Command | Key |
|---|---|
| New Document | Ctrl+N |
| Open a file | Ctrl+O |
| Save current file | Ctrl+S |
| Save all files | Ctrl+Shift+S |
| Close current file | Ctrl+W |
| Close all files | Ctrl+Shift+W |

## Changing a key

Select **File > Settings > Bindings**, find the command (typing in the filter box narrows the list) and select **Change…**. Press the combination you want. Escape on its own cancels; Escape with a modifier is a combination like any other, so Ctrl+Escape can be bound.

**Bind nothing** leaves a command with no key. **Reset** restores one command's default, **Reset all** restores every default.

Only the keys you change are saved, so a command whose default improves in a later release follows the new one unless you have chosen something yourself. If you pick a key another command already uses, the editor says which.
